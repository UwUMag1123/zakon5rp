# Кодекс Murrieta (zakon5rp)

Полная законодательная база сервера Murrieta (GTA 5 RP).

## Состав

- **6 кодексов** — Конституция, УАК, ПК, Судебный, Трудовой, Дорожный
- **24 закона** — LSSD, LSPD, FIB, USSS, EMS, оружие, прокуратура и др.
- **40 прецедентов и толкований** — по номерам дел (№22 … №3100)
- Методичка и лекции

## Как открыть

Открой `index.html` локально или через GitHub Pages.

Данные в `docs.json` (массив `{id, section, sectionName, title, text}`).
