# Кодекс Murrieta

Законодательная база RP-сервера Murrieta (GTA 5 RP): кодексы, законы, судебные прецеденты и решения
Верховного суда — полными текстами, с поиском, постоянными ссылками на каждый документ и готовым
системным промптом для ИИ-юриста.

Сайт: **https://zakon5rp.pages.dev**

## Что внутри

| Файл / папка | Что это |
|---|---|
| `docs.json` | **Единственный источник истины.** Массив `{id, section, sectionName, title, text}` |
| `index.html` | Приложение: реестр слева, лист документа справа, поиск, промпт для ИИ |
| `docs/index.html` | Оглавление со ссылками на все документы (работает без JS) |
| `docs/<id>.html` | Постоянная страница одного документа — для людей и для ИИ-агентов |
| `codex.json`, `law.json`, `appeal.json`, `other.json` | Порезанная база: запасной путь загрузки и удобные URL для отдельных разделов |
| `sitemap.xml`, `robots.txt`, `404.html`, `_headers` | Служебные файлы для поисковиков и Cloudflare Pages |
| `build.py` | Генератор всего перечисленного из `docs.json` |
| `tests/` | Проверки логики поиска и внутренних ссылок |

Всё, кроме `docs.json`, `index.html`, `build.py` и `tests/` — **генерируется**. Руками не править:
следующая сборка перезапишет.

## Как обновить базу

1. Добавьте или поправьте запись в `docs.json`:
   ```json
   {
     "id": "law-25",
     "section": "law",
     "sectionName": "Законы",
     "title": "Закон «О чём-нибудь»",
     "text": "Полный текст без сокращений…"
   }
   ```
   `id` — уникальный, вида `<раздел>-<номер>`. Разделы: `codex`, `law`, `precedent`, `appeal`,
   `casebook`, `course`.
2. Пересоберите статику:
   ```bash
   python build.py
   ```
3. Прогоните проверки и закоммитьте:
   ```bash
   node tests/logic.test.mjs
   node tests/links.test.mjs
   python build.py --check
   git add -A && git commit -m "Добавлен закон о чём-нибудь" && git push
   ```

CI (`.github/workflows/ci.yml`) на каждый push проверяет, что сгенерированные файлы не разъехались
с `docs.json` — забыть пересобрать не получится.

## Статусы документов

Статус выводится из заголовка, отдельного поля в данных нет:

| Признак в `title` | Статус |
|---|---|
| `[УТРАТИЛ СИЛУ]` | приглушённый пункт в списке, красная плашка в документе |
| `На рассмотрении` | плашка «на рассмотрении» |
| всё остальное | действующий |

Дата документа тоже берётся из заголовка (`… от 14.09.2024 …`), если она там есть. Ничего не
додумывается: нет даты в заголовке — нет даты на странице.

## Поиск

Морфология сделана без внешних библиотек: слово запроса усекается до основы по списку русских
окончаний и получает право на 0–3 буквы окончания. Поэтому «убийство» находит «убийства»,
«лицензия» — «лицензии», «статья» — «статьи». Цифры и латиница ищутся точным совпадением.

Проверить на реальной базе:

```bash
node tests/logic.test.mjs
```

## Для ИИ-агентов

- `https://zakon5rp.pages.dev/docs.json` — вся база одним JSON (≈2,9 МБ);
- `https://zakon5rp.pages.dev/docs/index.html` — оглавление;
- `https://zakon5rp.pages.dev/docs/<id>.html` — один документ на одной странице (для инструментов,
  которые обрезают большие файлы).

Готовый системный промпт с правилами цитирования открывается кнопкой «Промпт для ИИ-прокурора»
на сайте.

## Деплой

Cloudflare Pages, ветка `main`, корень репозитория, без шага сборки — всё статическое.
Файл `_headers` задаёт кеширование и базовые защитные заголовки.

### Известное ограничение

Домен `*.pages.dev` целиком недоступен из России на уровне провайдеров (TLS-соединение сбрасывается,
при этом `developers.cloudflare.com` открывается). Сайт при этом жив и доступен из других стран.
Для русскоязычной аудитории нужен собственный домен или другой хостинг со своим доменом.
