Промпт для ИИ

Скопируйте в системный промпт любой нейросети — она получит полный контекст законодательства Murrieta и инструкцию, как им пользоваться.

Для ИИ‑агентов: каждый документ открывается напрямую по адресу вида #codex-1 (раздел‑номер — см. список слева). Полные данные доступны программно по относительному пути docs.json (JSON‑массив объектов {id, section, sectionName, title, text}) — модель с доступом к открытой странице может получить его через fetch. Если инструмент модели читает веб‑страницы постранично и обрезает большой docs.json (2+ МБ), используйте лёгкие статичные страницы: список всех документов (docs/index.html), конкретный документ — docs/<id>.html (например docs/codex-2.html) с полным текстом без сокращений на одной странице.

Зеркала. Домен pages.dev в России режется провайдерами, поэтому та же база лежит ещё в двух местах — этих адресов достаточно, чтобы модель прочитала документы, даже если сайт у неё не открывается: cdn.jsdelivr.net/gh/UwUMag1123/zakon5rp@main/docs.json (вся база) и cdn.jsdelivr.net/gh/UwUMag1123/zakon5rp@main/docs/<id>.html (один документ); то же самое на raw.githubusercontent.com/UwUMag1123/zakon5rp/main/…. Для людей без VPN: uwumag1123.github.io/zakon5rp.
